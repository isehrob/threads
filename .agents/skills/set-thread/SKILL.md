# Set Thread

Read `~/threads/workflow.md`; follow its history schema exactly when writing.

Use the canonical path under `~/threads/topics`, never cwd discovery.

1. Use provided names; list only the minimum candidates needed if ambiguous.
2. Read topic knowledge and full thread history; open referenced artifacts only as needed.
3. Read the latest recorded `work_dir` and verify it before editing.
4. Summarize the objective, completed work, current state, and next step.
5. Keep the topic and thread path in context across compactions.
6. Leave history unchanged unless explicitly asked to record a handoff or close the thread.
7. Wait for the user's next direction.
