# Create Topic

Read `~/threads/workflow.md` if you need system context.

Use `~/threads/topics` as the fixed store, independent of cwd.

1. Use the provided name or derive a short kebab-case slug.
2. Create `~/threads/topics/<topic>/knowledge/` and `threads/`.
3. Do not overwrite an existing topic; report it instead.
4. Confirm the created topic path.
