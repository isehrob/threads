# Close Thread

Read `~/.local/share/threads/workflow.md`; follow its history schema exactly.

Use the topic and thread path established in context; if absent, ask instead of searching.

1. Read its full history; open artifacts only when the history shows they matter.
2. Keep only learnings that prevent meaningful future rediscovery.
3. Update or create concise files under the topic's `knowledge/`.
4. Include the source thread in each knowledge file.
5. Append an entry whose content starts `Thread closed.` and summarizes the outcome.
6. Do not delete or rewrite thread history or artifacts.
